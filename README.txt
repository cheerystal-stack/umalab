UMA LAB α 0.1 - CSV import experiment

1. Upload all files in this folder to a GitHub repository (same directory).
2. Enable GitHub Pages and open the page in Safari on iPhone.
3. Tap "同梱サンプルを表示" to load the included Fukushima 6R data.
4. Alternatively select races.csv, entries.csv and optionally past_runs.csv.
5. Tap a horse to view details. Imported data is stored in localStorage.
6. Use JSON backup before clearing browser data.

Notes:
- This is a prototype, not a live JRA data feed.
- The sample race is a debut race; past runs are empty.
- Only the first race is shown in this version.
- Horse IDs are not yet available.
